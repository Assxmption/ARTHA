# Statistical Arbitrage Backtester

## Overview
The **Statistical Arbitrage Backtester** (`app/quant/statarb_backtest.py`) converts the signal logic from the [[Stat_Arb_Screener]] into a simulated trading strategy. It takes cointegrated pair signals and runs a historical simulation to generate a unified daily return series.

## Architecture & Implementation
This module bridges the gap between theoretical pair cointegration and realistic trading execution.

### Key Components:
- **Signal Ingestion**: Consumes `PairSignal` sequences (Entry, Exit, Stop-loss) generated by `statarb.py`.
- **Trade Simulation**: 
  - Simulates entering and exiting long/short spread trades.
  - Tracks open position state and forces exit on signal reversal or max holding days (prevents zombie positions).
- **Transaction Costs**: Models realistic round-trip brokerage and market impact (e.g., 15 bps per leg).
- **Universe Aggregation**: Contains logic (`backtest_pair_universe`) to test multiple discovered pairs and return an aggregated set of results.

## Role in the Pipeline
Like the [[Factor_Backtester]], this module outputs a specific strategy sleeve (mean-reversion pairs trading). The resulting P&L stream is ingested by the [[Multi_Strategy_Engine]] for optimal capital allocation.

## Constraints
- **AGENTS.md Rule 1**: Purely deterministic backtesting.
- **AGENTS.md Rule 6**: Signals must clear this backtester (walk-forward OOS) before they are marked valid.
