# Factor Library

Located in `app/quant/factors.py`.

The repository of core quantitative factors evaluated by the [[Quant_Engine]].

- **Equities Signals**: Momentum, mean-reversion, and volatility-regime signals.
- **Commodities (MCX) Signals**: 
  - Seasonality (e.g., agri commodities following harvest cycles).
  - Term-structure signals (contango vs. backwardation).
