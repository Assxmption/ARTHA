# Quant Narrator Agent

**Status**: Implemented
**Path**: `app/agents/quant_narrator_agent.py`

Translates the output of the [[Quant_Simulator]], [[Alpha_Loop]], and [[Quant_Backtester]] into professional, plain-language text.

## Workflow
1. **Read Validated Signals**: Pulls `QuantSignal` facts from the Fact Store. Critically, it ONLY reads signals where `validated=True` (cleared the walk-forward gate).
2. **Read Backtest Reports**: Loads the latest JSON backtest report generated by the simulator.
3. **Narrate**: Explains the current regime (BULL/BEAR), strongest signals, portfolio-level Sharpe/drawdown, and risk posture.

## Fallback Mechanism
If the LLM call fails (e.g., rate limit), it utilizes a deterministic template-based fallback (`_fallback_narration`) to guarantee the pipeline completes.

## AGENTS.md Compliance
- **Rule 1 (No Math)**: The agent NEVER calculates z-scores, regime probabilities, or Sharpe ratios. It only narrates what the Quant Engine already output.
- **Rule 10 (Traceability)**: Every numeric claim cites the specific `fact_id` of the quant signal.
