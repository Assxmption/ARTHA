# ML Alpha Model v2

## Overview
The **ML Alpha Model** (`app/quant/ml_alpha.py`) implements a stacked ensemble machine learning architecture for predictive asset ranking. It replaces the naive v1 model with a robust, market-neutral design intended to yield genuine out-of-sample predictive power.

## Architecture & Implementation
The v2 model incorporates several structural protections against overfitting, look-ahead bias, and market beta noise. 

### Key Components:
- **Target Engineering**: Predicts the cross-sectional **RANK** of excess returns rather than raw absolute returns. This inherently removes market beta and bounds the target variable to $[0, 1]$.
- **Winsorization**: Raw forward returns are clipped (e.g., 2nd/98th percentiles) prior to ranking to reduce model sensitivity to extreme outlier events.
- **Walk-Forward Training with Purge Gap**:
  - Uses an **expanding window** (monotonically growing training set).
  - Enforces a strictly observed **Purge Gap** (e.g., 5-10 trading days) between the end of the train set and start of the test set to eliminate overlapping return look-ahead bias.
- **Stacked Ensemble**:
  - **Base Learners**: Tree-based models (`HistGradientBoostingRegressor`, `RandomForestRegressor`) capture non-linear feature interactions.
  - **Meta-Learner**: A strongly regularized linear model (`Ridge`) combined via IC-weighted averaging (based on in-sample Information Coefficient).

## Role in the Pipeline
The model ingests features generated by the [[Factor_Library]] (augmented with momentum and interaction terms) and outputs a daily `AlphaModelResult` (predictions, OOS IC, R²). This powers the predictive leg of the [[Multi_Strategy_Engine]].

## Constraints
- **AGENTS.md Rule 1**: Purely deterministic model training and inference. LLMs are never involved in predictions.
